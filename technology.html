The one-way principle

Overview of the one-way principle

Terafence’s data diode uses an FPGA-based design to enforce one-way data flow in hardware. Data can flow outward from the protected side, while incoming data is blocked entirely, which prevents tampering or hacking of connected devices such as OT assets, cameras, sensors and PLCs.

Flow direction is embedded in the FPGA, with no MAC, IP or CPU addresses, so data is relayed by physical electrical stimulation rather than by software-controlled networking. The protected side therefore has no addressable stack for an attacker to scan, exploit or reconfigure remotely.

This differs from a firewall, which filters traffic in both directions using software rules. A diode removes the return path altogether, so even a compromised external network has no channel back in.

How it works

  • Direction is fixed in the FPGA logic: data can leave the protected side, and no return path exists

  • No MAC, IP or CPU addresses on the data path, so there is nothing to scan, exploit or reconfigure remotely

  • Data moves as physical electrical signals, not routable network traffic

  • No operating system in the data path, so there is no OS to patch or compromise

Where diodes sit in a network

Where FPGA data diodes sit in the network

“One-way protection at every level: macro segmentation at the zone boundary, micro segmentation at the machine.”

Macro segmentation: the zone boundary

The diode sits between large network zones, such as the OT/control network and IT or a DMZ. It enforces a one-way boundary between whole zones.

  • Telemetry, logs and historian data flow out to IT and the cloud.
  • Nothing can travel back into the control network.
  • Typical for plants, utilities and critical infrastructure.

Micro segmentation: the asset boundary

A compact diode sits in front of an individual PLC, camera, sensor or machine. Each asset or line becomes its own protected segment.

  • Every device can send data out but can’t be reached from the network.
  • A compromise of one machine can’t spread to its neighbours.
  • This is where a small form factor matters most.

Used together

The strongest design layers both. Macro segmentation keeps the plant network safe from IT, and micro segmentation limits the blast radius inside the plant. Firewalls usually still handle traffic inside each segment.
